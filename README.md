# EASY CAST
Cast your phone to a TV / projector at full quality. Two apps: `phone` (sender) and `tv` (receiver).

## Build the APKs (no Android Studio needed)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab, run "Build Easy Cast APKs" (it also runs on every push).
3. Download the `EasyCast-APKs` artifact: `phone-debug.apk` and `tv-debug.apk`.

## Install
- Phone (Motorola): install `phone-debug.apk`.
- Hontion TV stick / HY320: install `tv-debug.apk` (USB drive + file manager, or the Downloader app).

## Use
Phone and TV on the same Wi-Fi. Open Easy Cast on the TV, then on the phone tap your TV.
- **Cast Video**: pick a video; TV plays it in original quality. TV remote: OK/Play-Pause, Left/Right = -/+10s, Back = stop.
- **Mirror Screen**: choose quality (720p / 1080p / 4K) and start. Back on the TV remote ends it.
